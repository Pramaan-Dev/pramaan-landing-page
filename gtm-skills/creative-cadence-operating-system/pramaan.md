# Run "Creative cadence operating system" with Pramaan

The skill says what to do. This page says which Pramaan superpowers do each step. Setup (key, MCP, SDK or HTTP): https://www.pramaan.dev/skill.md

## Step by step

| Skill step | Pramaan id | Notes |
|---|---|---|
| 2. Concept sourcing | `ads.creative.brief` | Copy ideas from the user's best Meta ads and competitors' public ads. Needs a connected ads account. Drafts only. |
| 2. Concept sourcing | `ad.intel` | Competitors' ads from the public library, grouped into themes. |
| Image-first validation: iterate into other formats | `ad.variants.make` | A winning image ad turned into new sizes, translations or one varied element. |
| When to retire a creative | `ads.creative.fatigue` | Ads whose clicks per impression fell while spend held. |

The agent sets the iteration hierarchy, the 50/30/20 split, the production formula and the quality scores itself.

## Before running

1. Quote each id first (`quote`). Nothing runs during a quote, and it returns the maximum price.
2. None of these ids send or change anything.
