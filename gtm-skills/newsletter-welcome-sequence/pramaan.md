# Run "Newsletter welcome sequence" with Pramaan

The skill says what to do. This page says which Pramaan superpowers do each step. Setup (key, MCP, SDK or HTTP): https://www.pramaan.dev/skill.md

This skill is writing. No superpower is needed, except optionally `llm.complete` to draft the emails in the sequence.

The agent does every step itself. No Pramaan id sets up an automated welcome sequence, so the user loads the five emails into their own email tool.

## Before running

1. Quote `llm.complete` first (`quote`). Nothing runs during a quote, and it returns the maximum price.
2. No id here needs approval.
