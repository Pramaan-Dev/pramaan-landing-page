# Run "Pain-point SEO audit" with Pramaan

The skill says what to do. This page says which Pramaan superpowers do each step. Setup (key, MCP, SDK or HTTP): https://www.pramaan.dev/skill.md

## Step by step

| Skill step | Pramaan id | Notes |
|---|---|---|
| Stage 1: list the pages that earn organic traffic | `seo.domain.trend` | Ranking pages and keywords by position band over time. Estimates, not the user's analytics. |
| Stage 1: sort pages into the three groups | `web.read` | Read a page to place it as pain-point, learning or unaligned. |
| Stage 2 and test 3: comparison page neutrality | `web.read` | Read the user's vs, alternatives and pricing pages. |
| Stage 1: Intent Void check | `keyword.gap` | Optional. Buyer keywords rivals rank for and the user's site does not. |

Conversions, opportunity touchpoints and form emails come from the user's analytics and CRM. The agent does the four tests and the verdict itself.
