# Run "Credit packaging" with Pramaan

The skill says what to do. This page says which Pramaan superpowers do each step. Setup (key, MCP, SDK or HTTP): https://www.pramaan.dev/skill.md

No superpower is needed. This is a credit schedule, tiers and a rate card, worked out from the product's own costs. Optionally use `llm.complete` to word the buyer explanation. The agent does every step itself.

## Before running

1. Quote `llm.complete` first (`quote`). Nothing runs during a quote, and it returns the maximum price.
2. It sends nothing.
