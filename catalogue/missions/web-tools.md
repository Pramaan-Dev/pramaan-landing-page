# Missions: Web tools

Read, scrape and watch any website, or drive a real browser.

- `site.pdf.archive`: Archive site pages as PDFs. Print the pages of a site, or the pages you pick, to dated PDFs in hosted storage. (steps: web.map, web.pdf-bulk)
- `site.ask`: Ask a question of a website. One question answered from one site's own pages: the site's pages are read, ranked against the question, and the answer names the pages it rests on. (steps: web.map, web.read, text.rerank, llm.complete)
- `domain.attach`: Attach a domain to a project. Attach an exact domain to a project, optionally read DNS, and make bounded verification attempts. (steps: domains.add, security.dns.lookup, domains.verify)
- `page.health.audit`: Audit a page's speed and health. One page's status, size, on-page score, load speed and Core Web Vitals, with the problems found. (steps: web.page.audit, web.uptime.check, web.page.speed-versions.list, web.page.speed-audits.list, web.page.speed, web.page.speed-options)
- `site.faq.build`: Build an FAQ from a website. Questions and answers written from a site's own pages: the site is crawled, and each question names the page its answer comes from. (steps: web.crawl, llm.complete)
- `domain.register`: Buy a domain name. Check and quote an exact domain, approve its purchase and optionally upsert and read back DNS records while retaining their old values. (needs approval; steps: domains.registration.search, domains.registration.quote, domains.registration.create, domains.registration.get, domains.dns-records.list, domains.dns-records.apply)
- `page.flow.capture`: Capture a browser session step by step. Walk through a supplied browser session, capture each action, then request its closure. (needs approval; steps: browser.session.get, browser.page.navigate, browser.page.wait, browser.page.click, browser.page.type, browser.page.read-markdown, browser.page.screenshot, browser.session.close)
- `brand.name.availability`: Check a brand name is free. Whether a company name is free as a domain and as a public handle, with web results that show clashes. (steps: web.domain-names.check, web.username.check, web.search)
- `site.crawlability.audit`: Check what search crawlers see on a site. What a crawler sees of a site: robots rules, sitemap size and freshness, the pages known and the known pages missing from the sitemap. (steps: web.robots.parse, web.sitemap.parse, web.site.crawled-pages, web.map)
- `domains.expiry.check`: Check when your domains expire. When a list of domains expires: the expiry date, days left counted at read time, registrar and registry statuses, one row per domain. (steps: security.domain.whois)
- `page.compare`: Compare two web pages. Two pages compared: what each says that the other does not, and where they differ. (steps: web.read, llm.complete)
- `speed.compare`: Compare your page speed with rivals. Your pages against competitors' on the same device and throttling, side by side. (steps: web.page.speed-bulk, web.page.speed-options)
- `site.crawl.index`: Crawl a site into your search index. A site crawled and stored as searchable vectors in an index you already have: every page's text, chunked, embedded to fit the index and upserted with its address. (steps: vector.index.get, web.crawl, text.embed, vector.vectors.upsert)
- `links.tracked.create`: Create tracked short links. A short link for each destination and channel, each destination read and safety-checked first, returned as a table. (steps: web.read, security.url.check, links.short.create, links.short.get)
- `monitor.changes.digest`: Digest what your monitors caught. Everything your monitors caught in a period, grouped by monitor and ranked by size of change, with failed checks listed apart. (steps: web.monitor.changes, web.monitor.inventory, web.monitor.runs-list, llm.complete)
- `web.task.run`: Do a task on a website. Carry out one approved goal on a public website and return its reported outcome. (needs approval; steps: browser.task.run)
- `site.download.fetch`: Download files from a site. Download new files in an existing session, copy confirmed files to your storage, then approve their removal and optional session closure. (needs approval; steps: browser.downloads.list, browser.page.navigate, browser.page.click, browser.download.get, browser.download.delete, browser.session.close)
- `page.extract`: Extract fields from a web page. Structured fields from one web page: each value is kept only when it occurs in the page text, and a field the page does not state says so. (steps: web.read, web.extract)
- `site.extract`: Extract the same fields from a whole site. The same structured fields from many pages of one site: every page the site map lists (or those matching a term) is read and extracted once, each value kept only when it occurs in that page's own text. (steps: web.map, web.read, web.extract)
- `form.fill`: Fill in and submit a web form. Fill named fields in an existing session, verify their exact values, then submit after approval. (needs approval; steps: browser.session.get, browser.page.navigate, browser.script.run, browser.page.type, browser.page.click, browser.page.read)
- `links.broken.find`: Find broken links on a site. Broken, redirected and slow links across a site, each with its redirect chain. (steps: web.map, web.redirects.trace, web.uptime.check, web.domain.redirects)
- `domain.network.map`: Find domains linked to a domain. Domains tied to a given domain by shared identifiers, redirects and page code, as a list with the evidence for each tie. (steps: web.domains.related, web.domain.redirects, web.domains.by-html, web.domain.email-inspect)
- `pages.similar.find`: Find pages similar to a page. Pages like a given page: the similarity source's candidates, each read and given a one-sentence summary written from its own text and checked against it. (steps: web.similar, web.read, llm.complete)
- `site.links.structure`: Map a site's internal links. A site's internal linking: best-linked pages, orphans, outbound domains and top authority pages. (steps: web.site.internal-links, web.site.top-pages, web.backlinks.top-pages, web.backlinks.pages-summary, web.outbound-domains.list, web.outlinks.summary)
- `page.read.reliable`: Read a page that blocks bots. Read the text of a page, trying a plain read, browser controls, a bot-protected read and rendered HTML in turn, and say which worked. (steps: web.read, web.read-advanced, web.read-unblocked, web.render.html)
- `walkthrough.record`: Record a walkthrough of a web page. Record a bounded sequence of page opens and clicks, close the recorded session with approval and export each requested page as a stored MP4. (needs approval; steps: browser.session.create-advanced, browser.page.navigate, browser.page.click, browser.session.close, browser.recording.export)
- `domain.renew.watch`: Renew domains close to expiry. List a page of owned domains, quote those close to expiry and approve each bounded-price renewal. (needs approval; steps: domains.registration.list, domains.registration.quote, domains.registration.renew)
- `links.performance.report`: Report clicks on your short links. Clicks per day for a set of short links over a chosen window, ranked, with links that got none flagged. (steps: links.short.clicks.get, links.short.get, llm.complete)
- `site.accessibility.report`: Report on a site's accessibility. Accessibility violations across a site's key pages, grouped by rule with the worst pages first. (steps: web.map, web.accessibility.audit, llm.complete)
- `uptime.report`: Report on a site's uptime. Checked availability and sampled slow responses for one monitor and time window. (needs approval; steps: apps.connections.list, apps.catalog.search, apps.action.execute)
- `tech.market.report`: Report on a technology's market share. How many sites use a technology, by rank band, language, country and category, and what it is used with. (steps: web.tech.adoption, web.tech.summary, web.tech.co-usage)
- `page.capture`: Screenshot a web page and read its text. Capture a rendered screenshot and separately read the matching page's text. (steps: web.screenshot, web.read)
- `site.stack.changes`: See what technology a site added or dropped. The technologies a site added or dropped since a date, checked against a fresh scan. (steps: web.tech.changes, web.tech.detect, web.tech.scan)
- `form.upload.submit`: Submit a web form with files. Fill exact named values and files in an existing owned form session, read each value back, then approve one submission and check its acknowledgement. (needs approval; steps: browser.page.read, browser.page.type, browser.page.upload, browser.script.run, browser.page.screenshot, browser.page.click)
- `page.summarize`: Summarise a web page. One web page in a paragraph and key points, written only from the page itself. (steps: web.read, llm.complete)
- `site.summarize`: Summarise a whole website. What a whole site is about: its pages read one by one, one sentence on each, and a written overview that names the pages it rests on. (steps: web.map, web.read, llm.complete)
- `domain.transfer-out`: Transfer a domain out. Read an owned domain, check it can be transferred, unlock it after approval, read it back and say how to get the one-time transfer code. (needs approval; steps: domains.registration.get, domains.registration.update)
- `monitor.spend.tidy`: Trim paid monitors that never change. Review paid monitor checks with no observed change and propose pausing, slowing or approved deletion. (needs approval; steps: web.monitor.inventory, web.monitor.runs-list, web.monitor.delete)
- `pricing.change.watch`: Watch a competitor's pricing page. Watch a competitor's pricing page on a schedule after approval, with the plans before and after each change. (needs approval; steps: web.monitor.inventory, web.pricing.extract, web.monitor.create-interval, web.monitor.changes)
- `page.change.watch`: Watch a page for changes. Start a scheduled check on one page, sitemap or set of facts after approval, and read recent changes with a sentence quoting each. (needs approval; steps: web.monitor.inventory, web.monitor.create-interval, web.monitor.changes, llm.complete)
