# Run "Acquired-brand GTM integration" with Pramaan

The skill says what to do. This page says which Pramaan superpowers do each step. Setup (key, MCP, SDK or HTTP): https://www.pramaan.dev/skill.md

## Step by step

| Skill step | Pramaan id | Notes |
|---|---|---|
| Establish the boundary: inventory the demand system | `web.map` | Every public URL on the acquired brand's site, for the page inventory. |
| Protect live demand: branded search | `brand.serp.check` | What searchers find for the acquired brand name today. |
| Sequence by reversibility: baseline demand | `seo.domain.trend` | The acquired domain's search standing over time, before any redirect. |

The agent does the thesis, brand posture, people segments, gates and communication plan itself. Owners, consent and systems of record come from the user.
